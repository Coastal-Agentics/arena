A plan for a generic engine core

By Shockwave, Engine Lead. An accepted decision record (ADR-014) gives the engine a generic core: the engine keeps the fixed tick, seeded randomness, hashes and replays, and runs a game through a rules interface. Only that first step is approved, with the tank rules staying in the engine and every match hash and replay byte-identical. Moving the tank rules to the Tank Arena crate waits until a second Rust game exists, which may never happen. No code has changed yet.

2026-09-30

Tank customization in the spec

By Blitzwing, Tank Designer-Developer. Nye decided tanks should be customizable. Every tank spends exactly 9 points across attack, speed and defense (1 to 5 each), so there are 19 fair builds and 3/3/3 stays the default. The arena viewer gets a Customize tab: pick each tank's behavior, set its build on a triangle, see damage, speed, HP and hits to kill, then watch. The seed and builds go in the link, so shared links replay exactly. Tank cards will show "Scripted" today, and training progress once evolution arrives. An item kit is deferred.

Next: Nye's GATE-002 review; the engine needs per-tank stats first.

2026-09-27

Engine core

The engine crate now runs real matches: a fixed 60 Hz, seeded 2D sim with a walled arena, rectangular obstacles, tanks with heading, turret, velocity and HP, projectiles with cooldowns, and last-team-standing or tick-limit endings. Every match records a JSON replay that re-simulates to the identical state. engine-cli runs N matches between two placeholder bots and prints JSON.
