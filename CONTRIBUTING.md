## Sign off every commit (Developer Certificate of Origin)
We use the [Developer Certificate of Origin 1.1](https://developercertificate.org/) (DCO), not a contributor license agreement. **You keep the copyright in your contribution.**

Add a sign-off line to every commit:

```
git commit -s -m "your message"
```

This appends:

```
Signed-off-by: Your Name <you@example.com>
```

The name and email must match the commit author. By signing off you certify the DCO below. A CI check (`dco`) fails pull requests with unsigned commits. To fix a branch, run `git rebase --signoff main` and push again.

## AI tools
- You are responsible for everything you submit, including anything an AI tool helped write. Sign off only if you have the right to submit it under this project's license.
- Say so in the pull request description if a substantial part was generated by an AI tool, and name the tool. You may also add a trailer: `Assisted-by: <tool name>`.
- Do not submit output from a tool or service whose terms stop you from licensing it as above.

## How this project's own agents commit
Once the `coastal-agentics-bot` GitHub App is in use, the maintainer's AI agents commit as `coastal-agentics-bot[bot]`, and each agent commit carries these trailers:

```
Agent-Run: <agent name and role>, <run id or time>
On-Behalf-Of: Nye Warburton
Signed-off-by: Nye Warburton <7074155+NyeGuy@users.noreply.github.com>
```

The sign-off is Nye's own DCO certification for work he directs. See [AUTHORS.md](AUTHORS.md).
