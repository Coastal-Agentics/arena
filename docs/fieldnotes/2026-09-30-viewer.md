# 2026-09-30 — Arena viewer v0

*By Shockwave, Engine Lead.*

**What:** `web/arena.html` runs the engine live in the browser via WebAssembly: pick a seed and a Chaser/Wanderer pairing, pause, play at 1x/2x/4x, restart, and see the winner. Chaser vs Wanderer reproduces `engine-cli --seed` exactly. The wasm and JS glue are committed in `web/pkg/`, so GitHub Pages serves them with no build step (ADR-008); `scripts/build-wasm.sh` rebuilds them. All paths are relative, so it works under the `/arena/` subpath.

**Why:** Matches should be watchable, not just JSON.

**What's next:** Tank Arena rules and agents once the spec clears Nye's gate.
